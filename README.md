Do erre immilator

A simple desktop application for writing, editing, and saving melodies
using Python and PySide6. The generated SongCompact code can be used at
[www.gitaartoonladders.nl](https://www.gitaartoonladders.nl).

## Features

- Enter lyrics syllable by syllable
- Convert syllables into colored note blocks
- Select pitches
- Generate SongCompact code
- Convert SongCompact code back into blocks
- Save songs to a text file
- Filter, sort, load, and delete songs
